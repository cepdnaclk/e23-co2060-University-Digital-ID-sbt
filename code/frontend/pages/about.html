PeraSoul / Digital Student Identity

System Overview

Digital student identity without publishing personal data on-chain

PeraSoul separates student profile information from blockchain identity state. Personal and academic data are maintained by the application database while the blockchain stores the token ownership and validity information needed for verification.

🧑‍🎓

Students

Register a wallet, authenticate with MetaMask, request a Digital Student ID, monitor token validity and access QR verification.

🏛️

University Administrators

Approve registrations, review token requests, issue identities, revoke identities and perform controlled wallet replacement.

🔎

Public Verifiers

Check whether an identity is currently valid using a QR verification link or token reference without accessing administrative data.

Application Layer

HTML, CSS and JavaScript frontend communicating with a FastAPI backend and SQLAlchemy/SQLite database.

Blockchain Layer

PeraSoul and PeraSoulManager smart contracts deployed on Ethereum Sepolia and accessed through Web3.py.

Security Model

Wallet-signature authentication, JWT-protected administrator APIs, non-transferable tokens, role checks and auditable blockchain operations.

PeraSoul Digital ID

A blockchain-based university digital student identity system using MetaMask authentication and non-transferable Soulbound Tokens.
