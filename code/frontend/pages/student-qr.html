Secure QR Verification

The QR contains a short-lived signed verification reference rather than embedding private student data.

Short-Lived Verification
⏱ 10-Second Validity

Each QR code remains valid for only ten seconds before the backend rejects it.

🔐 Signed Reference

The QR contains a cryptographically signed verification token rather than editable student information.

⛓ Current Blockchain Status

Scanning the QR retrieves the current identity state from PeraSoul and Ethereum Sepolia at verification time.

Scan From Another Device

For mobile-phone scanning during a local demonstration, the phone and computer must be able to reach the same frontend server. If the system is opened using 127.0.0.1 or localhost, another device cannot access that address.
