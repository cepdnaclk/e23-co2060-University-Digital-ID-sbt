Administrator Wallet Login

Connect an authorized MetaMask wallet and sign the server-generated challenge to access the appropriate PeraSoul administration portal.

Protected university access

Administrative actions are restricted to authorized PeraSoul administrator accounts. University Administrators manage student identity operations, while Technical Administrators manage administrator access.

Connect a registered administrator MetaMask wallet.
PeraSoul requests a unique nonce-based login message from the backend.
MetaMask signs the challenge locally; the private key never leaves the wallet.
The backend verifies the wallet signature and creates a protected JWT session.
Your assigned administrator role determines which management dashboard you can access.
