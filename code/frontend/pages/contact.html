📝

Registration Support

If registration is pending, wait for an authorized university administrator to review the submitted student details.

🔐

Wallet Access

PeraSoul never asks for a private key or seed phrase. Wallet ownership is proven only through MetaMask signatures.

🪪

Identity Support

For revocation or lost-wallet cases, contact an authorized university administrator so the identity can be reviewed before any state-changing action.

Important Security Notice

Never send a wallet private key, seed phrase, MetaMask recovery phrase or administrator signing key through a contact message. PeraSoul operations do not require disclosure of these secrets.
